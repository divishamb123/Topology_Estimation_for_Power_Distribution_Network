The Bus-Injection to Branch-Current matrix encodes the tree topology of the distribution network. A value of 1 means that branch carries the injected current from that bus.

The Branch-Current to Bus-Voltage matrix maps branch currents to voltage drops. Active entries represent the impedance (in Ω) of each branch along the path from the slack bus.
